SYSTEM OVERVIEW

About DefectVision AI

An industrial surface inspection system combining automatic multi-model comparison, defect classification, independent anomaly screening, explainable AI, evidence-based validation, spatial analysis, and inspection reporting.

What the system does

The application accepts an industrial surface image and automatically evaluates the same image using three registered CNN models: ResNet18, MobileNetV2, and Custom CNN.

The model outputs are compared automatically and the strongest model result is selected for the remaining inspection pipeline. The selected model then performs defect classification and provides the confidence distribution.

The inspection station also produces an independent visual anomaly screen, severity and priority assessment, Grad-CAM model attention, controlled evidence-preserved and evidence-removed views, a spatial evidence profile, and a final inspection report.

Why anomaly screening matters

The anomaly layer is independent of the classifier. It searches for locally unusual texture and gradient patterns, allowing the inspection workflow to flag unusual regions even when a classifier is confident in a known class.

Important: the anomaly score is a screening signal, not a calibrated probability of defectiveness.

Processing pipeline

01 · INPUT Surface image Upload a JPG or PNG industrial surface image for inspection.
02 · COMPARE Multi-model comparison The same image is automatically evaluated by ResNet18, MobileNetV2, and Custom CNN.
03 · SELECT Best model selection The three model predictions are compared and the strongest model result is automatically selected.
04 · CLASSIFY Defect classification The selected model predicts one of six trained defect classes and provides the complete confidence distribution.
05 · ANOMALY Visual anomaly screening Local texture residual and gradient information are analyzed to highlight unusual surface patterns.
06 · SEVERITY Severity & priority assessment Visual evidence, anomaly response, affected area, and supporting signals are combined into an inspection-priority assessment.
07 · EXPLAIN Grad-CAM Grad-CAM visualizes the regions that most influenced the selected model prediction.
08 · VALIDATE Evidence consistency Highlighted evidence is preserved and suppressed to measure how strongly the prediction depends on that evidence.
09 · PROFILE Spatial evidence analysis The system summarizes evidence pattern, location, affected area, and orientation.
10 · REPORT Export inspection report The final report contains the selected best model, prediction, confidence, anomaly analysis, evidence results, spatial profile, and visual inspection evidence.
